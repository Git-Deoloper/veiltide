# Roadmap

The most valuable improvements will be driven by actual users and reproducible test cases, not a feature-count race.

## Next

- Add a richer highlight/diff view that does not reveal sensitive values in analytics.
- Improve detector coverage for common OAuth and database connection formats.
- Add opt-in, local-only named profiles for repetitive masking workflows.
- Publish an accessibility and performance audit of the deployed site.

## Later

- Configurable rules as an optional local JSON file for CLI use.
- First-class IPv6 and internationalized email handling.
- Streaming CLI processing for large log files without high memory usage.
- Multi-language documentation and community-contributed examples.

Security upgrades should favor better false-negative handling, clear user expectations, and safer defaults before new features.
