# Changelog

## 1.0.0 — First public-ready source release

- Local-first web redaction studio with split before/after editor.
- Reusable masking labels, configurable categories, and custom literal terms.
- Text import, explicit copy/download controls, and offline-capable app shell.
- No-dependency command-line interface with safe output-file defaults.
- Original website artwork and security-focused release documentation.
- Automated tests and GitHub Actions verification.
